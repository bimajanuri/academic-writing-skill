# Extraction Module — Meta-Ethnography (1st / 2nd Order Constructs)

Data extraction guide for the Meta-Ethnography Mode. Provides strict rules for separating the **two layers of data** that will be fed into the Reciprocal Translation Engine.

## Key Concepts

| Layer | Definition | Source in Paper |
|-------|----------|-----------------|
| **1st Order Constructs** | Original **participant (respondent) quotes** — verbatim, in quotation marks | Quotes/responses in the Results/Data section |
| **2nd Order Constructs** | **Author's interpretation/theory** of participant data — themes, concepts, categories proposed by the author | Themes/Theoretical framework/Interpretation |

> **3rd Order Constructs** are the outcome of your synthesis — DO NOT extract them from the paper; they are generated by `engines/reciprocal-translation.md`.

## Extraction Rules

1. Quote 1st order **verbatim**, with quotation marks and identity (page/paragraph) when available.
2. 2nd order is written as the author's claim (e.g. "The author frames X as a form of Y").
3. A single paper can hold multiple constructs — record all of them.
4. If the paper presents only quotes without explicit interpretation → mark the 2nd order as "—", do not fabricate.
5. Each construct is assigned a unique ID (e.g. `S1-1st-01`) for traceability in the engine.

## Minimum Columns

| Study (Author/Year/Journal/Q) | Construct ID | Type (1st/2nd) | Text/Quotes | Page/Par | Context | Quality (CASP) |
|------------------------------|--------------|----------------|-------------|-------------|---------|-----------------|

## Anti-Hallucination

- Distinct requirement: 2nd order is not a word-for-word restatement of 1st order.
- Verify every quote exists in the paper (mark "QUOTE VERIFY" if not sure).
- Record population and setting context so constructs are not detached from context.
