# Grammar Check — Tata Bahasa & Mekanika (Bahasa Indonesia / English)

Panduan memeriksa tata bahasa, ejaan, tanda baca, dan konsistensi bahasa pada naskah akademik — **dua bahasa: Bahasa Indonesia dan English**. Dipakai di **Tahap 5 (Layer Grammar)** dan sebelum submission (Tahap 6).

> Bedakan dari Humanizer (Layer 1): humanizer menangani *gaya khas-AI*; grammar check menangani *kebenaran linguistik* sesuai kaidah bahasa. Keduanya bisa saling terkait, tetapi ceknya berbeda.

## 1. Workflow Grammar Check

1. **Deteksi bahasa dominan** tiap bagian (Indonesia / English / campuran) — jangan mencampur kaidah.
2. **Cek mekanis dulu** (pola yang bisa diburu otomatis, §2–§3 per bahasa).
3. **Cek tata bahasa** (agreement, tense, struktur kalimat, preposisi).
4. **Cek ejaan & kata** (kata baku untuk ID; spelling untuk EN).
5. **Cek tanda baca & format** (kapitalisasi, koma, semicolon, tanda kutip).
6. **Cek konsistensi** (istilah, bentuk istilah dari Tahap 5 gate mekanis, ejaan Inggris-British/US dipilih satu).
7. Jika tersedia, jalankan **LanguageTool** (gratis, mendukung ID & EN) sebagai pelengkap, lalu verifikasi sarannya secara manual — jangan terima mentah-mentah.

## 2. Bahasa Indonesia — Kaidah Penting

Acuan: **EYD** (Permendikbudristek No. 18 Tahun 2022, "Ejaan Bahasa Indonesia yang Disempurnakan"; menggantikan PUEBI) dan KBBI untuk kata baku.

### 2.1 Kata baku vs tidak baku (contoh umum)
| Baku | Tidak baku |
|------|-----------|
| analisis | analisa |
| apotek | apotik |
| atlet | atlit |
| cabai | cabe |
| februari → Februari (kapital), tetapi bulan | Februari |
| formal | formil |
| hakikat | hakekat |
| izin | ijin |
| jadwal | jadual |
| karier | karir |
| nasihat | nasehat |
| praktik | praktek |
| risiko | resiko |
| sistem | sistim |
| telepon | telpon |
| ubah | rubah (untuk "mengubah"; rubah = binatang) |

> Selalu verifikasi keraguan ke KBBI (kbbi.kemdikbud.go.id). Jangan mengarang kata baku.

### 2.2 Awalan `di-` / `ke-` (tempat) vs kata depan `di` / `ke` (kata kerja dan lokasi)
- Preposisi lokasi **ditulis terpisah**: `di rumah`, `di atas meja`, `ke Jakarta`.
- Awalan **sambung**: `dibaca`, `diketik`, `kehendak` (bukan kata tempat).
- Tes: jika bisa `di ... sana` / `ke ... sana` → pisah. Jika menjadi kata kerja → sambung.

### 2.3 Partikel
- `-lah`, `-kah`, `-tah`, `-pun`: melekat (rapat) — `bacalah`, `apa pun`. Pengecualian: `adapun`, `andaipun`, `bagaimanapun`, `biarpun`, `kendatipun`, `meskipun`, `sekalipun`, `walau pun`, `walaupun` (semua ditulis serangkai sebagai kata).
- `pun` yang adalah kata (makna "juga") ditulis terpisah: `mereka pun setuju`.

### 2.4 Huruf kapital
- Awal kalimat; nama orang, tempat, lembaga, negara, bangsa, bahasa, suku, agama, hari, bulan (tetapi **bukan** nama mata uang, arah, gejala).
- **Gelar dan jabatan tidak dikapitalisasi** kecuali sebagai sapaan.
- Judul buku/makalah/article: kata pertama dikapitalisasi di Bahasa Indonesia (judul tidak full-title-case seperti Inggris; ikuti konvensi "hanya kata awal").

### 2.5 Tanda baca
- Koma sebelum konjungsi? Dalam ID, koma **tidak dipakai** sebelum "dan" pada daftar (tidak ada serial comma): `A, B, dan C`.
- Tanda kutip ganda `"..."` untuk kutipan; tanda kurung untuk keterangan tambahan.
- Titik untuk desimal di ID (dan koma untuk ribuan): `Rp1.500,00`; **kebalikan** dari Inggris.

### 2.6 Kalimat efektif
- Subjek-verba-objek jelas; hindari kalimat tanpa subjek.
- Hindari pemborosan: "untuk dapat melakukan" → "untuk melakukan"; "sangat amat" → pilih satu.
- Runtut: hubungkan kalimat dengan konjungsi bermakna.

## 3. English — Kaidah Penting

Acuan: MLA/CMOS/AP house style sesuai jurnal; konsisten British OR US spelling.

### 3.1 Subject–verb agreement
- Singular/plural subjek harus cocok dengan verba: `The results show ...` (bukan `shows`).
- Kesalahan umum: `Each of the studies is ...`; `The number of participants was ...` vs `A number of participants were ...`.
- Subjek majemuk dengan `and` → plural; `or/nor` → ikut elemen terdekat.

### 3.2 Article usage (a/an/the)
- `a` sebelum bunyi konsonan (`a university`), `an` sebelum bunyi vokal (`an hour`).
- `the` untuk spesifik/known; tanpa artikel untuk general plural.

### 3.3 Tense consistency
- Manuscript convention: present tense untuk yang tetap berlaku (`we argue`, `Table 1 shows`), past tense untuk pelaporan hasil/aksi penelitian (`we collected`, `the results indicated`).
- Pilih satu tense per fungsi dan jaga konsisten antar bagian; jangan berpindah tanpa alasan.

### 3.4 Prepositions
- Kesalahan umum: `different from` (bukan `than`), `similar to`, `consistent with`, `based on`, `in contrast to` (bukan `with`).
- `compared with` (membandingkan kesamaan/perbedaan) vs `compared to` (analogi).

### 3.5 Punctuation
- **Serial comma** (Oxford comma) di MLA/Chicago: `X, Y, and Z`. (Kebalikan kaidah ID.)
- Comma splice: dua independent clauses dipisah koma tanpa konjungsi → ganti dengan titik/`;`/`and`/`but`.
- Semicolon untuk memisah klausa padat atau daftar yang mengandung koma.
- Apostrophe possessive: `the study's aim` (bukan `studies`); `its` tanpa apostrof (posesif), `it's` = it is.
- Quote: US memakai double quotes `"..."`; British memakai single `'...'` — konsistenkan dengan target.

### 3.6 Spelling register
- US: `analyze, color, center, modeling`; UK: `analyse, colour, centre, modelling`.
- Pilih SATU dan konsisten; jangan campur.

## 4. Pola Error Umum (deteksi cepat, ID & EN)

Kategori berdasarkan frekuensi kesalahan di naskah mahasiswa:

| Kategori | Indonesia | English |
|----------|-----------|---------|
| Agreement | Subjek–predikat (kata depan) | subject–verb agreement |
| Kata | baku/tidak baku (KBBI) | spelling US/UK |
| Preposisi | `di/ke` lokasi vs awalan | prepositions |
| Tense | (ID tidak berinfleksi — fokus pada aspek `sudah/sedang`) | tense consistency |
| Tanda baca | serial comma TIDAK ada | serial comma WAJIB (MLA/Chicago) |
| Kepemilikan | `-nya` vs `-Nya` (kata ganti Tuhan) | `its` vs `it's`, apostrophe |

## 5. Tools (Opsional)

- **LanguageTool** — gratis, API: `https://api.languagetool.org/v2/check`; mendukung `id` dan `en-US/en-GB`. Saran harus **diverifikasi manual** (false positive umum).
- **Grammarly / MS Editor** — untuk English, opsi berbayar; tidak boleh menjadi tolok ukur tunggal.
- **Hunspell** — dictionary spell checker (via CLI) untuk cek cepat ID/EN.

> Aturan utama: sarana otomatis membantu menemukan, manusia/AI memutuskan. Jangan ubah makna hanya karena "dipangkas tools".
