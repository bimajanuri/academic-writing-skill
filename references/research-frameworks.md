# Research Frameworks — Pilihan Framework Penulisan & Riset

Katalog framework yang dapat dipilih pengguna untuk mengikat cara paper diformulasikan, dilaksanakan, dan dilaporkan. Terdiri dari **3 kategori**:

1. **Framework Pertanyaan Penelitian (Research Question)**
2. **Framework Prosedur & Tahapan Riset**
3. **Framework Pelaporan & Screening (Reporting Checklist)**

> **Modular Multi-Method Engine**: untuk review kualitatif, framework pelaporan/ekstraksi disatukan dalam protokol mode (`protocols/scoping-review.md` → PRISMA-ScR + PCC; `protocols/meta-ethnography.md` → eMERGe + Noblit & Hare; `protocols/narrative-review.md` → SANRA; `protocols/integrative-review.md` → Whittemore & Knafl; `protocols/critical-review.md` → appraisal lenses). Lihat Method Selection Router di SKILL.md.

> Prinsip: framework adalah **kontrak yang mengikat** — begitu dipilih, RQ, pencarian, struktur metodologi, dan checklist akhir mengikutinya. Framework tidak wajib; jika pengguna tidak peduli, agent mengusulkan default sesuai jenis paper (lihat §4).

## 1. Framework Pertanyaan Penelitian (RQ Framework)

Pilih satu framework untuk memformulasikan 1–3 RQ. Setiap elemen framework menghasilkan komponen kalimat RQ sekaligus **kata kunci pencarian** (feed ke `literature-search.md`).

| Framework | Elemen | Cocok untuk (jenis pertanyaan) | Disiplin umum |
|-----------|--------|-------------------------------|---------------|
| **PICO(T/S)** | **P**opulation, **I**ntervention, **C**omparison, **O**utcome (+**T**ime / +**S**tudy design) | Efektivitas intervensi/eksperimen; pertanyaan kuantitatif | Kesehatan, teknik, sains alam |
| **PICo / PICoS** | **P**opulation/Participants, **P**henomena of **I**nterest, **C**ontext | Pengalaman/makna; sintesis bukti kualitatif (JBI-endorsed) | Keperawatan, sains sosial |
| **PEO** | **P**opulation, **E**xposure, **O**utcome | Aetiologi/risiko tanpa komparator; pengalaman terhadap paparan | Epidemiologi, sains sosial |
| **PCC** | **P**opulation, **C**oncept, **C**ontext | Scoping review (pemetaan wilayah literatur) | JBI-endorsed, multi-disiplin |
| **SPIDER** | **S**ample, **P**henomenon of **I**nterest, **D**esign, **E**valuation, **R**esearch type | Sintesis bukti kualitatif & mixed-methods | Kesehatan, sosial |
| **SPICE** | **S**etting, **P**erspective, **I**ntervention, **C**omparison, **E**valuation | Evaluasi layanan/intervensi, perubahan organisasi | Manajemen, kesehatan layanan |
| **ECLIPSe** | **E**xpectation, **C**lient group, **L**ocation, **I**mpact, **P**rofessionals, **S**ervice | Evaluasi kebijakan/layanan (kualitatif) | Kebijakan publik, manajemen |
| **CIMO** | **C**ontext, **I**ntervention, **M**echanisms, **O**utcome | Pertanyaan "apa bekerja, untuk siapa, kapan, mengapa" (realis/design science) | Pendidikan, bisnis, rekayasa |
| **CoCoPop** | **C**ondition, **C**ontext, **P**opulation | Pertanyaan prevalensi/kelaziman | Epidemiologi |
| **FINER** | **F**easible, **I**nteresting, **N**ovel, **E**thical, **R**elevant | **Validasi kualitas** RQ (bukan penyusun kalimat) | Semua |
| **5W+1H** | What, Who, Why, Where, When, How | Pertanyaan umum/eksploratif, jurnalistik riset | Semua |

> Rujukan: UCL Systematic Searching guide, Booth (2006), Cooke et al. (2012), Wildridge & Bell (2002), JBI Manual for Evidence Synthesis.

### Cara menggunakan
1. Pilih framework sesuai jenis pertanyaan (tabel di atas).
2. Isi setiap elemen → gabung jadi kalimat RQ terstruktur.
3. Ekstrak 3–5 konsep inti → turunkan kombinasi kata kunci untuk pencarian (Round 1 di `literature-search.md`).
4. Evaluasi kejelasan dengan **FINER** (Feasible/Interesting/Novel/Ethical/Relevant) sebelum dikunci.

### Contoh (PICO)
```
P: mahasiswa S1 Indonesia (18–25 tahun)
I: media sosial pembelajaran berbasis video (durasi & frekuensi)
C: tanpa intervensi / kelas sinkron konvensional
O: IPK, keterlibatan belajar
T: satu semester
RQ: "Pada mahasiswa S1 di Indonesia, apakah pembelajaran berbasis media sosial
     meningkatkan keterlibatan dan IPK dibanding kelas konvensional dalam satu semester?"
```

## 2. Framework Prosedur & Tahapan Riset

Menuntun **cara riset dijalankan** — dari desain sampai eksekusi/pelaporan proses. Pilih satu sebagai kerangka metodologi.

| Framework | Tahapan | Dipakai untuk |
|-----------|---------|---------------|
| **Research Onion (Saunders et al.)** | 1) Philosophy → 2) Approach → 3) Strategy → 4) Choices → 5) Time horizon → 6) Techniques & procedures | Memilih & membenarkan desain riset (kuantitatif/kualitatif/mixed), cocok utk research paper |
| **Empirical Cycle (de Groot)** | Observation → Induction → Deduction → Testing → Evaluation | Riset empiris sistematis; alur metode ilmiah |
| **Research Process Stages** | 1) Identifikasi masalah → 2) Tinjau literatur → 3) Tujuan/RQ/hipotesis → 4) Desain riset → 5) Pengumpulan data → 6) Analisis → 7) Interpretasi → 8) Pelaporan | Riset umum kuantitatif/kualitatif |
| **PRISMA-P (protokol)** | 17 item protokol (admin info, intro, metode: eligibility → informasi → strategi pencarian → telaah data & risiko bias → data → synthesis → dll.) | Menulis protokol systematic review/open review SEBELUM eksekusi |
| **Systematic Review Conduct (Cochrane/JBI-aligned)** | 1) Definisi pertanyaan → 2) Kriteria eligibilitas → 3) Strategi pencarian → 4) Screening & seleksi studi → 5) Penilaian risiko bias → 6) Ekstraksi data → 7) Sintesis (meta/deskriptif) → 8) Interpretasi & kesimpulan | Systematic review penuh |
| **4-Phase PRISMA Flow (screening)** | Identification → Screening → Eligibility → Included | Prosedur screening & laporan jumlah artikel (flow dari PRISMA 2020) |

### Screening (bagian dari prosedur, bukan pelaporan)
- Dua tahap: **title/abstract → full-text**, dilakukan **2 reviewer independen** + diskusi/adjudikasi.
- Deduplikasi di awal (reference manager atau script; laporkan jumlah unik vs sebelum dedup).
- Dokumentasikan jumlah pada tiap fase dalam **PRISMA flow diagram**.

> Jika paper bukan systematic review, gunakan Research Onion / Empirical Cycle / Research Process Stages sebagai kerangka metodologi; PRISMA-P & PRISMA Flow hanya untuk evidence-synthesis (systematic/scoping review).

## 3. Framework Pelaporan & Screening (Reporting Checklist)

Dipakai sebagai **checklist pelaporan** dan **crib sheet screening**. Sumber rujukan resmi: **EQUATOR Network** (equator-network.org), prisma-statement.org, consort-spirit.org, strobe-statement.org.

### 3B. Screening & critical appraisal (risk-of-bias) tools

| Tool | Dipakai untuk | Status template |
|------|---------------|-----------------|
| **PRISMA 2020 Flow** | Jumlah artikel tiap fase screening (reporting) | Diagram resmi prisma-statement.org |
| **Cochrane RoB 2.0** | Risiko bias RCT | Per domain (randomisasi, deviasi, missing data, pengukuran, seleksi hasil) |
| **ROBINS-I** | Risiko bias studi non-randomized (intervensi) | 7 domain |
| **Newcastle–Ottawa Scale (NOS)** | Kualitas kohort/kasus-kontrol | Seleksi, komparabilitas, outcome |
| **QUADAS-2** | Akurasi diagnostik | 4 domain |
| **JBI Critical Appraisal Checklists** | 10+ desain (kualitatif, cross-sectional, dll.) | Per desain (≥8 item) |
| **AMSTAR 2** | Kualitas metodologis systematic review | 16 item |
| **GRADE** | Keyakinan (certainty) bukti | 5 domain per outcome |

> "Screening" = dua hal: (1) **selection flow** (PRISMA Flow, §2), dan (2) **critical appraisal** (tools di 3B). Keduanya masuk laporan metodologi.

## 4. Rekomendasi Default per Jenis Paper

Jika pengguna tidak menyebut framework, usulkan (tapi minta konfirmasi):

| Jenis paper | Kategori 1 (RQ) | Kategori 2 (Prosedur) | Kategori 3 (Pelaporan/Screening) |
|-------------|------------------|------------------------|-----------------------------------|
| Systematic review (kuantitatif) | PICO / PICOS | PRISMA-P + Conduct Steps + 4-Phase Flow | PRISMA 2020 (+PRISMA-S, +PRISMA-Abstracts); RoB 2 / NOS; AMSTAR 2; GRADE |
| Systematic review (kualitatif) | PICo / SPIDER | PRISMA-P + Conduct Steps + 4-Phase Flow | ENTREQ; JBI; PRISMA 2020 (adjusted) |
| Scoping review | PCC | PRISMA-P (scoping-aware) + 4-Phase Flow | PRISMA-ScR (+PRISMA-S) |
| RCT | PICO / PICOT | Research Process Stages | CONSORT 2010 |
| Observasional (kohort/kasus-kontrol/cross-sectional) | PEO / PICO | Research Process Stages | STROBE |
| Riset kualitatif (wawancara/FGD) | SPIDER / SPICE | Empirical Cycle / Research Onion | COREQ (atau SRQR) |
| Literature review / konseptual / manajemen | CIMO / 5W+1H | Research Onion | Internal quality gates (internal checklist) |
| Riset kebijakan/layanan | ECLIPSe / SPICE | Research Process Stages | STROBE / CHEERS (jika ekonomi) |

> Catatan: tidak semua jurnal mewajibkan checklist EQUATOR. Selalu cek **Instructions for Authors** jurnal target; jika tidak mewajibkan, penggunaan checklist tetap direkomendasikan untuk kualitas.

## 5. Alur Kerja di Pipeline

1. **Tahap 1 (Langkah 1.1)** — minta pengguna memilih framework (atau usulkan default via §4). Simpan ke `framework_selection.md`.
2. **Tahap 1 (Langkah 1.2)** — bangun kata kunci pencarian dari elemen RQ framework.
3. **Tahap 2 (Langkah 2.1)** — formulasikan RQ dengan framework terpilih; validasi FINER.
4. **Tahap 2 (Langkah 2.5)** — tetapkan bagaimana framework prosedur & reporting checklist diterapkan pada outline; tandai posisi item checklist tiap section.
5. **Tahap 3** — tulis metodologi mengikuti framework prosedur; barrier-artefak screening (RoB table, PRISMA flow numbers) dibuat saat hasil masuk.
6. **Tahap 6 (Langkah 6.3)** — jalankan checklist pelaporan terpilih lewat `templates/reporting_checklist.md`; pastikan setiap item punya lokasi di naskah.
