# Novelty & Contribution Framing — From Gap to Proven Contribution (Stage 2)

Novelty is not a magic sentence in the introduction. Novelty is an **accountable statement** about what differs from the literature — derived from the gap validated in Stage 1 (see `references/research-gap-mapping.md`). This module ensures the contribution is formulated early (Stage 2), tested by evidence during writing (Stage 3), and does not overclaim.

## 1. Gap → Novelty

The direct relationship between the gap type and your "what's new":

| Gap Type (from Gap Matrix) | Claimable Contribution |
|------------------------------|------------------------------|
| Theoretical | Theory extended/tested/corrected for a case not yet explained by theory |
| Methodological | New method/design/measurement, or an adaptation to a new context |
| Contextual | New findings from an untouched population/location/time |
| Inconsistency | New explanation reconciling contradictory findings (moderator/mediator) |
| Competitive ("everything has been studied" gap) | Reframing or a new combination — not a "we are first" claim |

**Rule**: the contribution must state *how* it differs, not merely *that* it differs.

## 2. Five Forms of Novelty Recognized by Journals

Paper claims generally fall into one, or a combination, of these five forms:

1. **New combination** — joining two previously separate domains/theories/methods.
2. **New context/object** — applying a proven framework to a new population/location/time.
3. **New method/approach** — new analytical technique, instrument, design, or pipeline.
4. **New findings** — new data that changes the understanding of an already-studied relationship.
5. **Reframing** — a new lens that synthesizes the literature into a clearer structure.

> One of the most common mistakes: claiming form 4 ("new findings") while still at the level of form 2 ("new context"). An honest novelty label avoids disappointing reviewers and curbs overclaiming.

## 3. Writing the Contribution Statement

One "backbone" sentence plus 2–4 bullets (claim-first format, see also `references/outline-builder.md` §2.4).

```
Backbone sentence: "This paper contributes to <domain> by <main claim> through <how/evidence>."
```

- Claim-first: start from the contribution, not from the topic.
- Every bullet MUST be provable by the evidence planned in the paper.
- Write it in Stage 2 (planning), then **re-validate** in Stages 3 & 5 against the actual evidence.
- Use the template `templates/contribution_statement.md`.

Example:

```
This paper contributes to the literature on social media use and academic performance
by showing that duration (not frequency) predicts GPA, by separating
the two dimensions that were previously combined.
1. Separate measurement of duration vs. frequency (new instrument, Cronbach ≥ .80).
2. Regression evidence that duration > 4 hours lowers GPA by 0.4 points (p < .01) in a sample of Indonesian students.
3. A self-regulation moderation model that reconciles contradictory results in previous studies.
```

## 4. Validation Before Use

Before the contribution enters the outline & intro:

| Check | Criterion |
|-----|----------|
| Differs from existing | Can show the source/evidence in the matrix for the "not yet done" claim |
| Provable | Every bullet has planned evidence |
| Significant enough | Not merely patching one parameter onto a baseline (incremental patching) |
| Matches a novelty form | Honest label (combination/context/method/findings/reframing) |
| No overclaiming | "First paper in X" only if the literature search is truly empty |

If it fails a check → return to Gap Analysis: the gap is too weak or the contribution direction has not been chosen.

## 5. Positioning the Contribution in the Paper

- **Introduction**: contribution as a numbered list, claim-first (see `references/section-writing.md` §3.2).
- **Literature Review**: a "Research Gap & Position of This Paper" section links the same gap to the contribution (do not use the source papers as "losing" comparisons, but rather as nudges/diagnosis).
- **Discussion**: the contribution is brought back to the evidence, not merely repeating claims.
- **Conclusion**: a summary of the contribution now supported by evidence.
- **Cover letter**: one contribution paragraph (feed Module B `references/journal-targeting.md`).

## Output

```
contribution_statement.md  — backbone + contribution bullets + evidence map + validation
```
