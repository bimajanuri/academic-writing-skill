# Composable Academic Revision Patterns

Select patterns from the diagnosis instead of applying every transformation mechanically. Follow each pattern with a local claim-evidence and terminology check.

| Pattern | Trigger | Operation |
|---|---|---|
| `method-lock` | any new review | lock mode, framework, reporting standard, and inclusion criteria |
| `claim-evidence-map` | substantive section | map each major claim to evidence and status |
| `source-integrity` | citations or extracted studies | verify DOI, metadata, quotes, and attribution |
| `de-slop-academic` | template prose or inflated framing | remove filler and significance inflation; preserve scope |
| `terminology-lock` | repeated constructs or variables | choose one term and record aliases |
| `translation-fidelity` | Indonesian input | translate asserted content into English-US without added certainty |
| `grammar-mechanical` | revision or submission | run the English-US checklist; reject meaning-changing suggestions |
| `reporting-checklist` | final manuscript | run the mode checklist and remediate incomplete items |
| `guardrail-diff` | every output | compare claims, literals, citations, quotes, and evidence |

Default composition:

```text
method-lock → claim-evidence-map → source-integrity → de-slop-academic
→ terminology-lock → translation-fidelity → grammar-mechanical
→ reporting-checklist → guardrail-diff → evaluation
```
