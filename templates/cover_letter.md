# Cover Letter — Introduction Template for Journal Editors

Maximum 1 page. Personalize per journal. Feed the contribution from `contribution_statement.md` (Module A) and the fit argument from `journal-targeting.md` (Module B).

## Header Format

```
To the Editor-in-Chief,
<journal>
<address/online portal>

<date>
```

## Paragraph 1 — Identity & Substance

```
Dear Editor,

We are submitting our manuscript entitled "<Title>" for consideration
for publication in <Journal>. This manuscript presents <one sentence: topic + core finding>.
```

## Paragraph 2 — Fit with the Journal (fit argument)

```
The topic of this manuscript falls within the scope of <Journal>, as stated on the
journal's website: "<quote of the scope statement>. <1–2 sentences: explain how this paper
addresses the journal's concerns>.
<Supplement: 1–2 citations of papers from <Journal> closest to this research>
```

- Avoid excessive flattery; stay factual.
- Quote the journal's scope exactly (without misquoting), then explain the fit.

## Paragraph 3 — Contribution (claim-first, not "novel/groundbreaking")

```
This manuscript contributes to <domain> through <main claim> supported by <core evidence>:
1. <contribution 1 (akin to the contribution_statement.md bullets)>
2. <contribution 2>
3. <contribution 3>
```

- Use the content of `contribution_statement.md` §3 verbatim (final, validated version).
- Do not add empty adjectives.

## Paragraph 4 — Statements & Declarations

```
We declare that this manuscript has not been published and is not under
consideration by any other journal. All authors approve the content and order of authorship.
<Potential conflicts of interest, if any, are disclosed.>
<If the editor wishes, we are willing to provide data for verification.>

Thank you for your consideration.
```

## Checklist Before Submission

- [ ] Journal & editor names correct (not template placeholders)
- [ ] Scope statement quoted accurately & from the official source
- [ ] Contributions identical to the final `contribution_statement.md`
- [ ] Citations from the target journal (if any) correct & relevant
- [ ] No empty claims (novel/groundbreaking/revolutionary)
- [ ] More than 1 page? trim
