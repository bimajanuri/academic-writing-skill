# Citation Template — Harvard

An **author-date** style widely used by international journals, especially in the UK and in economics/business/social sciences/health. The most common variant: **Cite Them Right (CTR) 11th edition**.

## In-Text Citation

| Situation | Format | Example |
|-----------|--------|---------|
| Narrative, 1 author | `Name (Year)` | Rahman (2023) |
| Parenthetical, 1 author | `(Name, Year)` | (Rahman, 2023) |
| 2 authors | `Name and Name` | Rahman and Sari (2023) |
| 3+ authors | `Name et al.` | (Rahman et al., 2023) |
| Direct quotation | `(Name, Year, p. 210)` | (Rahman and Sari, 2023, p. 210) |
| No author | `(Title, Year)` | (Social Media, 2023) |
| Organization | `(Organization Name, Year)` | (WHO, 2023) |

- Use `p.` for a single page and `pp.` for a range inside a direct quotation.
- No comma before `et al.` in some journal variants; follow the target journal's author guidelines.

## Reference List

General format:
```
Last Name, A. and Last Name, B. (Year) 'Article title', Journal Name, Volume(Issue), pp. page–page. doi: 10.xxxx/xxx.
```

### Example — Journal:
```
Rahman, A. and Sari, D. (2023) 'The influence of social media on students' academic performance', Indonesian Journal of Psychology, 12(3), pp. 210–225. doi: 10.4324/xxxx.
```

### Book:
```
Rahman, A. (2008) Adolescent psychology. Jakarta: Rajagrafindo Persada.
```

### Chapter in Book:
```
Rahman, A. (2023) 'Inquiry-based learning', in Sari, D. (ed.) Educational innovation. Bandung: Remaja Rosdakarya, pp. 45–67.
```

### Conference Article:
```
Rahman, A. (2023) 'Paper title', in Proceedings of the Conference Name. City: Publisher, pp. 10–20.
```

### Web:
```
Rahman, A. (2023) Page title. Available at: https://url (Accessed: 3 March 2025).
```

## Additional Rules
- Author names: `Last Name, Initial.` — list all authors (some variants limit them and then use `et al.`).
- Year in parentheses after the author's name.
- **Article titles in single quotation marks** (different from APA, which has no quotation marks); **journal/book titles italicized**.
- Volume italic, issue in parentheses, pages with `pp.` prefix.
- DOI written as `doi: ...` (not the full URL) in the CTR variant.
- Reference list alphabetical.
- Variants differ between journals — if the target journal has author guidelines, follow those (note the variant in `style_profile.md`).

## Checklist
- [ ] Consistent author-date (year always accompanies the name)
- [ ] Article title in single quotes; journal/book italic
- [ ] `pp.`/`p.` for pages; `pp. page–page`
- [ ] DOI in `doi: ...` format
- [ ] All in-text ↔ reference list pairs consistent 1:1
