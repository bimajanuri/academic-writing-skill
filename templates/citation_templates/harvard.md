# Template Sitasi — Harvard

Gaya **author-date** yang banyak dipakai jurnal internasional, terutama di Inggris dan bidang ekonomi/bisnis/sosial/kesehatan. Varian paling umum: **Cite Them Right (CTR) 11th edition**.

## In-Text Citation

| Situasi | Format | Contoh |
|---------|--------|--------|
| Naratif, 1 penulis | `Nama (Tahun)` | Rahman (2023) |
| Kurung, 1 penulis | `(Nama, Tahun)` | (Rahman, 2023) |
| 2 penulis | `Nama and Nama` | Rahman and Sari (2023) |
| 3+ penulis | `Nama et al.` | (Rahman et al., 2023) |
| Kutipan langsung | `(Nama, Tahun, p. 210)` | (Rahman and Sari, 2023, p. 210) |
| Tanpa penulis | `(Judul, Tahun)` | (Media Sosial, 2023) |
| Organisasi | `(Nama Organisasi, Tahun)` | (WHO, 2023) |

- Gunakan `p.` untuk satu halaman dan `pp.` untuk rentang di dalam kutipan langsung.
- Tanpa koma sebelum `et al.` di beberapa varian jurnal; ikuti author guidelines jurnal target.

## Daftar Pustaka (Reference List)

Format umum:
```
Belakang, A. and Belakang, B. (Tahun) 'Judul artikel', Nama Jurnal, Volume(Issue), pp. halaman–halaman. doi: 10.xxxx/xxx.
```

### Contoh — Jurnal:
```
Rahman, A. and Sari, D. (2023) 'Pengaruh media sosial terhadap prestasi akademik mahasiswa', Jurnal Psikologi Indonesia, 12(3), pp. 210–225. doi: 10.4324/xxxx.
```

### Buku:
```
Rahman, A. (2008) Psikologi remaja. Jakarta: Rajagrafindo Persada.
```

### Bab dalam Buku:
```
Rahman, A. (2023) 'Pembelajaran berbasis inkuiri', in Sari, D. (ed.) Inovasi pendidikan. Bandung: Remaja Rosdakarya, pp. 45–67.
```

### Artikel Konferensi:
```
Rahman, A. (2023) 'Judul paper', in Proceedings of the Nama Konferensi. Kota: Penerbit, pp. 10–20.
```

### Web:
```
Rahman, A. (2023) Judul halaman. Available at: https://url (Accessed: 3 March 2025).
```

## Aturan Tambahan
- Nama penulis: `Nama Belakang, Inisial.` — semua penulis dicantumkan (beberapa varian membatasi lalu `et al.`).
- Tahun dalam tanda kurung setelah nama penulis.
- **Judul artikel dalam tanda kutip tunggal** (berbeda dari APA yang tanpa kutip); **judul jurnal/buku italic**.
- Volume italic, issue dalam kurung, halaman dengan prefix `pp.`
- DOI ditulis `doi: ...` (bukan URL penuh) pada varian CTR.
- Daftar pustaka alfabetis.
- Varian berbeda antar jurnal — jika jurnal target punya author guidelines, ikuti panduan tersebut (catat variannya di `style_profile.md`).
