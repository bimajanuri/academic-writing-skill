# Citation Template — Turabian (9th Edition)

A Chicago-derived style for **student papers, theses, dissertations, and humanities/social sciences articles**. Turabian has two systems: **Notes-Bibliography** (humanities, history, literature) and **Author-Date** (sciences, social sciences). Choose ONE system and use it consistently.

---

## Option A — Notes-Bibliography

### Footnote / Endnote
| Situation | Format | Example |
|-----------|--------|---------|
| Full note (first) | `N. First Name Last Name, "Article Title," Journal Name Vol, no. Issue (Year): page.` | 1. Ahmad Rahman and Dewi Sari, "The Influence of Social Media on Students' Academic Performance," Indonesian Journal of Psychology 12, no. 3 (2023): 210–225. |
| Repeated (short) citation | `N. Last Name, "Short Title," page.` | 2. Rahman and Sari, "The Influence of Social Media," 212. |
| Book | `N. First Name Last Name, Book Title (City: Publisher, Year), page.` | 3. Ahmad Rahman, Adolescent Psychology (Jakarta: Rajagrafindo Persada, 2008), 45. |
| Web | `N. First Name Last Name, "Title," Site Name, access date, URL.` | 4. Ahmad Rahman, "Social Media and Adolescents," Kompas, accessed March 3, 2025, https://url. |

Abbreviations recognized by Turabian: `Ibid.` (same source as the immediately preceding note), and the short form after the first note.

### Bibliography
```
Last Name, First Name, and First Name Last Name. Year. "Article Title." Journal Name Vol, no. Issue (Year): page.
```
Journal example:
```
Rahman, Ahmad, and Dewi Sari. "The Influence of Social Media on Students' Academic Performance." Indonesian Journal of Psychology 12, no. 3 (2023): 210–225.
```
Book:
```
Rahman, Ahmad. Adolescent Psychology. Jakarta: Rajagrafindo Persada, 2008.
```

## Option B — Author-Date

### In-Text Citation
| Situation | Format | Example |
|-----------|--------|---------|
| Parenthetical | `(Name Year, page)` | (Rahman and Sari 2023, 210) |
| Narrative | `Name (Year, page)` | Rahman and Sari (2023, 210) |
| 3+ authors | `Name et al.` | (Rahman et al. 2023, 210) |

### Reference List
```
Last Name, First Name, and First Name Last Name. Year. "Article Title." Journal Name Vol (Issue): page.
```
Example:
```
Rahman, Ahmad, and Dewi Sari. 2023. "The Influence of Social Media on Students' Academic Performance." Indonesian Journal of Psychology 12 (3): 210–225.
```

---

## Additional Rules
- Name format: `Last Name, First Name` in the bibliography/reference list; `First Name Last Name` in footnotes.
- Page number right after the quotation mark: notes `: 210`; author-date `, 210`.
- Italicize book titles and journal names; put article titles in quotation marks.
- Bibliography alphabetical; notes follow order of appearance.
- DOI/URL: `https://doi.org/...` when available.
- Turabian = Chicago-based; the main differences concern details for student works (chapters, classroom notes, etc.).
