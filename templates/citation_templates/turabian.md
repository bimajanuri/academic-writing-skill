# Template Sitasi — Turabian (9th Edition)

Gaya turunan Chicago untuk **makalah mahasiswa, tesis, disertasi, dan artikel humaniora/sosial**. Turabian memiliki dua sistem: **Notes-Bibliography** (humaniora, sejarah, sastra) dan **Author-Date** (sains, sosial). Pilih SATU sistem dan pakai konsisten.

---

## Opsi A — Notes-Bibliography

### Catatan Kaki / Catatan Akhir
| Situasi | Format | Contoh |
|---------|--------|--------|
| Catatan penuh (pertama) | `N. Nama Depan Nama Belakang, "Judul Artikel," Nama Jurnal Vol, no. Issue (Tahun): halaman.` | 1. Ahmad Rahman dan Dewi Sari, "Pengaruh Media Sosial terhadap Prestasi Akademik Mahasiswa," Jurnal Psikologi Indonesia 12, no. 3 (2023): 210–225. |
| Kutipan ulang (pendek) | `N. Belakang, "Judul Pendek," halaman.` | 2. Rahman dan Sari, "Pengaruh Media Sosial," 212. |
| Buku | `N. Nama Depan Nama Belakang, Judul Buku (Kota: Penerbit, Tahun), halaman.` | 3. Ahmad Rahman, Psikologi Remaja (Jakarta: Rajagrafindo Persada, 2008), 45. |
| Web | `N. Nama Depan Nama Belakang, "Judul," Nama Situs, tanggal akses, URL.` | 4. Ahmad Rahman, "Media Sosial dan Remaja," Kompas, diakses 3 Maret 2025, https://url. |

Singkatan yang diakui Turabian: `Ibid.` (kutipan langsung sebelumnya, edisi sama), dan bentuk pendek setelah catatan pertama.

### Bibliografi
```
Belakang, Nama Depan, dan Nama Depan Belakang. Tahun. "Judul Artikel." Nama Jurnal Vol, no. Issue (Tahun): halaman.
```
Contoh jurnal:
```
Rahman, Ahmad, dan Dewi Sari. "Pengaruh Media Sosial terhadap Prestasi Akademik Mahasiswa." Jurnal Psikologi Indonesia 12, no. 3 (2023): 210–225.
```
Buku:
```
Rahman, Ahmad. Psikologi Remaja. Jakarta: Rajagrafindo Persada, 2008.
```

## Opsi B — Author-Date

### In-Text Citation
| Situasi | Format | Contoh |
|---------|--------|--------|
| Kurung | `(Nama Tahun, halaman)` | (Rahman dan Sari 2023, 210) |
| Naratif | `Nama (Tahun, halaman)` | Rahman dan Sari (2023, 210) |
| 3+ penulis | `Nama et al.` | (Rahman et al. 2023, 210) |

### Daftar Referensi
```
Belakang, Nama Depan, dan Nama Depan Belakang. Tahun. "Judul Artikel." Nama Jurnal Vol (Issue): halaman.
```
Contoh:
```
Rahman, Ahmad, dan Dewi Sari. 2023. "Pengaruh Media Sosial terhadap Prestasi Akademik Mahasiswa." Jurnal Psikologi Indonesia 12 (3): 210–225.
```

---

## Aturan Tambahan
- Format nama: `Nama Belakang, Nama Depan` di bibliografi/reference list; `Nama Depan Nama Belakang` di catatan kaki.
- Halaman langsung pada kutipan: catatan `: 210`; author-date `, 210`.
- Italic untuk judul buku dan nama jurnal; judul artikel dalam tanda kutip.
- Bibliografi alfabetis; catatan mengikuti urutan kemunculan.
- DOI/URL: `https://doi.org/...` bila tersedia.
- Turabian = basis Chicago; perbedaan utama ada pada detail untuk karya mahasiswa (bab, catatan kelas, dsb.).
